# Biometric Keypoint Detection & Feature Extraction

A batch-processing pipeline that extracts normalized descriptors from three biometric modalities and exports them to CSV files:

| Modality | Method | Output |
|---|---|---|
| Face | MediaPipe Face Landmarker (478 landmarks), normalized by nose position and inter-ocular distance | `outputs/features_faces.csv` |
| Fingerprint | CLAHE contrast enhancement + ORB keypoints | `outputs/features_fingerprint.csv` |
| Voice | MFCCs, spectral descriptors and pYIN fundamental frequency (librosa) | `outputs/features_voices.csv` |

## Project structure

    biometric_keypoints.ipynb      main notebook
    scripts/prepare_faces.py       samples 40 public LFW face images
    scripts/prepare_fingerprints.py generates 30 synthetic fingerprint patterns
    scripts/download_assets.sh     downloads the MediaPipe model and voice samples
    outputs/                       CSV files produced by the notebook
    requirements.txt               pinned dependencies

## Getting started

    python3 -m venv .venv && source .venv/bin/activate
    pip install -r requirements.txt
    python scripts/prepare_faces.py
    python scripts/prepare_fingerprints.py
    bash scripts/download_assets.sh
    jupyter notebook biometric_keypoints.ipynb

Run all cells from the repository root (**Kernel > Restart & Run All**).

## Processing details

- **Faces**: one face per image; coordinates are centred on the nose tip and divided by the inter-ocular distance, giving invariance to translation and scale (not rotation). Output: 40 rows x 28 columns.
- **Fingerprints**: images resized to 256x256, CLAHE, then up to 500 ORB keypoints; descriptors include keypoint count, density, mean response and size, position statistics and contrast. Output: 30 rows x 12 columns.
- **Voices**: 16 kHz mono, silence trimmed, amplitude normalized; 13 MFCCs (mean and standard deviation), spectral centroid, bandwidth, roll-off, zero-crossing rate, RMS and mean F0. Output: 60 rows x 35 columns.
- Every file is processed inside a `try/except` block; failures are recorded in a `status` column instead of stopping the batch.

## Results

All 40 face images, 30 fingerprints and 60 recordings were processed without errors. F0 could not be estimated for 11 of the 60 recordings (no voiced frames detected).

## Limitations

- ORB detects generic interest points, not true fingerprint minutiae (ridge endings and bifurcations).
- The fingerprints are synthetic concentric patterns, so their descriptors are very homogeneous.
- Face descriptors are not rotation-invariant; LFW images are small and tightly cropped.
- The voice dataset contains isolated digits (8 kHz, 6 speakers); mean/std MFCCs discard temporal dynamics.
- No biometric evaluation (FAR, FRR, EER) is performed.

## Data and licenses

No personal biometric data is included in this repository.

- Faces: [Labeled Faces in the Wild](http://vis-www.cs.umass.edu/lfw/) (Huang et al., 2007), downloaded through scikit-learn; not redistributed here.
- Voices: [Free Spoken Digit Dataset](https://github.com/Jakobovski/free-spoken-digit-dataset), CC BY-SA 4.0; downloaded by script.
- Fingerprints: synthetic, generated by `scripts/prepare_fingerprints.py`.
- Model: MediaPipe Face Landmarker (Google), Apache 2.0; downloaded by script.
